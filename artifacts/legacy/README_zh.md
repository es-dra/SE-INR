# Legacy Artifacts

本目录只保留有审计或历史恢复价值的旧产物，不属于当前论文证据入口。

## 使用边界

- 默认不能引用为正文或主表证据。
- 只有当 `paper/ARTIFACTS_ALLOWED.md` 或 claim ledger 明确重新晋级时，才可进入论文。
- 若 legacy 材料与 `artifacts/derived/benchmarks/`、`artifacts/derived/evidence/README_zh.md`
  或 `paper/model_taxonomy.md` 冲突，以当前 canonical 入口为准。

  provenance，仅供审计。

## 恢复条件

需要重新使用 legacy 产物时，应先写明来源、协议、与当前 canonical 结果的关系和禁止用途；
不能直接把 legacy 路径链接回 active 文档。
