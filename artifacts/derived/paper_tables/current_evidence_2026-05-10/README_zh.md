# Current Evidence Tables 2026-05-10

This directory is a compact paper-table planning artifact. It collects only short
summary values from existing canonical artifacts; it does not introduce new
benchmark measurements.

## Files

- `current_evidence_table.csv`: compact rows for candidate paper tables.
- `provenance.json`: source files used to build the table.

## Intended Use

Use this as a table-planning checklist before editing LaTeX. It preserves caveats
per row so preliminary seed1 evidence is not mixed with cite-ready 3-seed evidence.

## Key Caveats

- Final `SC-INR` multi-seed is running / pending.
- NoSinc consistency is diagnostic, not proof of better observation modeling.
- Selected qualitative figures remain selected examples only.
