# 预注册：D11 —— E1 切换点为何提前（σ_n=0.005 时 P1/P2 失败）的诊断

2026-10-05 写，此时还没有任何 D11 结果。

**跑前状态（诚实披露）。**
- 已看过 E1 各臂的 12 图平均 PSNR（e1_result_v2.json），因此 GP 各臂在各噪声档下的**排序已知**。
- **未看过**任何按频带的误差分解。
- 下面的预测量由命题 3 的公式机械算出，没有可调参数；公式和代入方式在此写死。

**算力。** GPU 0/2/3 正在跑 seed2/3 重训，GPU 1 属于别人，所以本诊断**只用 CPU**。因此只诊断线性的 GP 各臂；mrgrid、ff、TV 需要 GPU 训练，不在本次范围内。

## 1. 假设

E1 预注册的 P1 把 σ_n ≤ 0.005 归为 A 区，只依据了 b2 的事前预算（T=16、σ_n=0.005 时 b2 = 0.88）。但同一档下 b3 = 0.37（d8），已经是 B 区。按命题 3，B 区高估有代价，而宽谱（低偏置）先验在 b3 上就是高估。

据此预测：
- **D11-a（定位）**：σ_n=0.005 时，gp_gauss_30 相对 gp_oracle 的超额误差中，**≥ 50% 落在 b3**。
- **D11-b（命题 3 定量解释 GP 臂）**：σ_n ∈ {0.005, 0.01, 0.02} 时，对 8 个 GP 臂（gauss 3/10/30/60/128，power 2/2.5/3），预测超额误差为

  pred = Σ_b E_b · Δ(R_b, κ_b)

  它与实测超额误差 obs = Σ_b (err_arm,b − err_oracle,b) 的 Spearman ≥ 0.8，共 24 个（臂, 噪声）点，取 12 图平均。
- **D11-c（预测赢家）**：在每个噪声档上，pred 最小的非 oracle GP 臂就是实测 PSNR 最高的非 oracle GP 臂；3 档中至少 2 档一致。

## 2. 定义（写死）

- **数据与观测**：完全复用 e1gp.py 的设置：DIV2K 0801–0812，×4，T=16，对齐给真值，nv = max(σ_n², 1e-5)，CG 600 步，RGB。只改设备为 CPU，并输出重建结果。
- **频带**：在 HR 像素频率上取 m = max(|f_x|, |f_y|)，单位 cycles/px，按 m 分为 b1 [0, 1/8)、b2 [1/8, 1/4)、b3 [1/4, 1/2]。
- **能量计算**：取去边 8 px 的 240² 区域，对误差和信号都乘 2D Hann 窗再做 FFT，按频带求和，3 个通道相加。这沿用了 E2 修正后的度量。
  - E_b：真值信号在频带 b 的能量。
  - err_arm,b：该臂误差在频带 b 的能量。
  - R_b = 1 − err_oracle,b / E_b（逐图）。
- **失配倍数**：κ_b = Σ_{f∈b} P_arm(f) / Σ_{f∈b} P_oracle(f)，在 512² 环面频率网格上计算，P 就是传给 gp_map 的谱。
- **公式**：Δ(R, κ) = R(1−R)²(κ−1)² / (1−R+κR)²（命题 3）。R 截断到 [0, 1)。
- σ_n = 0 只做描述，不进判据（真实谱 GP 有数值下限，与 E1 预注册一致）。
- **统计**：报告 Spearman，并对 12 张图做 bootstrap（10000 次）给 95% CI。判定按点估计。

## 3. 决策

- **a 成立**：E1 切换提前，归因于"P1 只看了 b2、忽略了 b3 已处在 B 区"。修正后的事前规则交给推导线程。
- **b、c 成立**：命题 3 在多帧的线性臂上得到定量支持。
- **b 不成立**：频带平均的 κ 不足以解释，需要逐频率的版本，或者这里存在多帧特有的效应。
