# 预注册 L2b：cell 缺失 = 输出增益失配（2026-10-05）
依据：推导修正-v1 §3.4。写定时间早于下面任何量的计算。只用 L2 的现有模型做推理，不训练。
披露：seed1 的 L_act 和 L_pred（ρ 0.822 / 0.824）都已经看过；δ_b² 和下面两个乘积预测量还没有计算过。
## 定义（seed1，两对：LTE / LTE-NoCell，SC-INR / SC-INR-NoSinc；与 L2 相同的 27 格、相同图像和 cell 网格）
- δ_b²(s, 数据集) = Σ_图 ‖Π_b(f_marg − f_full)‖² / Σ_图 ‖Π_b f_full‖²。其中 Π_b 是与 F1 相同的频带投影，在去均值的灰度图上做；f_marg 是 L2 中 31 个 cell 线性取值的平均输出。
- R = R_full（网络在该格的 R）。
- P1 = δ_b²·R；P2 = δ_b²·R(1−2R)²。
## 判据（scipy Spearman，并列取平均秩，两对分别计算）
- H-L2b-1：ρ(P1, L_act) ≥ ρ(L_pred, L_act)（即 ≥ 0.822 / 0.824），两对都满足才算成立。
- H-L2b-2：ρ(P2, L_act) < ρ(P1, L_act)，两对都满足才算成立。
- 描述性：只看 δ_b² 本身时的 ρ；以及上述各量在 ×8 上的结果。
## 不能说什么
- 只有 seed1；推导是线性化的，H-L2b-1 不成立也不否定 L2 本身。
