# R(u) 与 PSNR 的关系，以及 SC-INR 路线的根本思考（Claude，2026-11-01）

本文回应两件事：审稿方对"恢复度 R(u) 与 PSNR 有什么区别"的质疑，以及对 SC-INR 路线从观测模型出发的重新评估。写作原则：只把仓库里跑过的实验当证据；此前我说的"cell 的价值上限约 0.1 dB"是推断而非证据，本文第二节明确收回。

## 一、R(u) 和 PSNR 到底差在哪

**同一个量的两种汇总。** 对一幅重建图，误差能量按 Parseval 可以分到各频段：MSE = Σ_b V_b。PSNR 把全部 V_b 加总后取对数；R_b = 1 − V_b/E_b 把每个频段的误差除以该频段的目标能量。所以 R(u) 不是一个新的"质量指标"，而是把 PSNR 里的那一个数拆成一条曲线。审稿方的质疑在这一层是对的，论文应当直接承认。

**真正不同的三点。**

1. **分频段。** 两个 PSNR 相同的模型可以有不同的 R(u)。仓库的核心发现（容量收益全部落在 u≳0.75、低频 ≤0.0013 不变）在 PSNR 里不可见。
2. **按目标能量归一化。** R_b 是"该频段目标能量中被解释的比例"，无量纲、有上界 1、可为负。对线性最优估计它等于该频段的相干平方，所以它有信号处理里的明确含义，而 PSNR 的 dB 没有频段含义。
3. **u 对齐。** 把频率除以 LR Nyquist 后，×2 的 u=1 和 ×4 的 u=1 是"同样相对于观测极限的位置"。这使不同倍率的曲线能画在一张图上比较。PSNR 跨倍率无法做这种对齐。

还有一个技术差别值得说明：R 先把所有图像的能量池化再取比值，PSNR 是逐图 dB 再平均。两者权重不同，可能给出不同的模型排序；前者由高能量图像主导。

**它看不见什么。** 空间位置（误差在哪个物体上）；相位错误与幅度错误（都计入误差能量）；通道协议（Y 通道 PSNR 与 RGB 能量不同）。文献里早有频谱误差曲线（谱偏置研究、HyRA 的低通分析、GAN 超分论文的频谱图），R(u) 的新意只在 u 归一化和"先登记预测再按频段评分"的用法。

**给审稿人的回答可以是一句话：** R(u) 是 PSNR 的频段分解，经目标能量归一化并按 LR Nyquist 对齐；它不替代 PSNR，而是回答 PSNR 回答不了的问题：收益落在哪个频段、来自观测还是先验。

**顺带修正一处前期表述。** 阶段 06 的数字显示，bicubic 在 ×2 的 u∈[0.75,1) 恢复度只有 0.64，u∈[0.5,0.75) 为 0.95，而网络在 [0.75,1) 达到 0.93。因此"u<1 的成分可由观测直接恢复"并不准确。更准确的三区划分是：u≲0.5 由观测直接给出，任何方法都饱和；0.5≲u<1 在观测带宽内但被抗混叠滤波衰减，需要学习的反卷积先验；u≥1 完全靠先验。这个划分有数据支撑，比开题初稿的两区划分更站得住。

## 二、收回"cell 的价值上限约 0.1 dB"

去掉 cell 后掉 0.1 dB，测的是**现有解码器**从 cell 里提取了多少，不是 cell 所含信息的价值。一个不会用 cell 的解码器，消融差自然小。仓库自己的证据反对把它当上限：阶段 02 显示 ×2 时把 cell 设错的代价约 2.4 dB，说明输出对 cell 高度敏感。所以"FiLM 顶多再榨零点零几 dB"是我未经验证的推断，不应作为否定试点的依据；试点结果仍应按冻结协议判定。

## 三、SC-INR 从观测模型出发重新想

### 3.1 它的主张

SC-INR 的主张可以一句话写出：**cell 不是一个条件 token，而是输出像素的物理足迹；输出像素值应当是连续表示在足迹上的积分。** 对局部傅里叶基 cos(πω·δ+φ)，在宽 c 的矩形足迹上积分有闭式，就是 sinc(ω_x c_x/2)·sinc(ω_y c_y/2)。于是尺度进入表示的方式从"学"变成"算"。代码里确实如此：`sc_inr_adaptive.py` 第 283–291 行分别对 c_x、c_y 取 sinc，频率 ω 由特征生成、不依赖 cell。

### 3.2 这个主张在哪里有力

一个学到的 token 只在训练分布内有定义；一个解析积分处处有定义。训练时 cell 只取过 c_x = c_y = 2/s，s∈[1,4]。于是四个场景同属一个命题"足迹空间的外推"：

- **非对称倍率**（c_x ≠ c_y）。LIIF 把 [c_x, c_y] 拼进第一层，LTE 把它送进相位线性层。训练数据永远是 [c, c]，只约束两列权重之和，各自的值由初始化决定。所以 LIIF/LTE 对非对称 cell 的响应在训练中没有被定义过，且应随种子变化。SC-INR 的横纵响应由解析式固定。
- **超出训练范围**（s>4，c<0.5）。LTE 官方把 cell 截断在训练下界；SC-INR 的 sinc(ω/s) 平滑地趋向 1。
- **缩小**（s<1，c>2）。此时 sinc 是一个真正的抗混叠预滤波。LIIF/LTE 没有任何机制避免混叠。
- **跨尺度一致性**。同一张 LR 的 ×4 输出按 2×2 盒平均后，应等于 ×2 输出。这是"任意尺度表示"的本义，LIIF/LTE 不满足，解析积分原则上满足。

### 3.3 为什么在对称 ×2–×4 上没有优势

那里 cell 的作用可以被学到，任何形式都能学到同样的东西。仓库的发现 1 正是这一预测的证据：四种解码器在训练覆盖的倍率上落在同一条 R(u) 曲线上。这不是 SC-INR 的失败，而是它的理论的第一条预测被证实。论文应当这样写，而不是把"没差别"藏起来。

### 3.4 现有实现的两处"不纯"，也是在 3.2 的场景里可能表现不如承诺的原因

1. **sinc 乘在基上，之后还有非线性 MLP。** 足迹积分的精确形式是 ∫MLP(Σ a_k φ_k)，实现的是 MLP(Σ a_k·sinc_k·φ_k)，两者不等。只有当输出对加权后的基是线性的，积分才精确。Thera 之所以能宣称"无混叠"，正是因为它的衰减作用在最后一个线性层的分量上。所以当前 SC-INR 是"足迹感知的特征"，不是"足迹积分的输出"。MLP 可以部分抵消 sinc 的作用，这也从另一面解释了它为什么与 LTE 等价。
2. **`upinput` 跳连是双线性插值，完全不看足迹。** s>1 时它只提供低频主干，无妨；s<1 时它会直接混叠，抵消 sinc 的抗混叠作用。

这两点决定了：在非对称和 s>4 场景，现有 SC-INR 仍可能优于 LIIF/LTE（因为 sinc 至少给了一个有定义的横纵分离响应）；在 s<1 和一致性场景，它未必兑现承诺，需要 3.5 的修正版。

### 3.5 由此导出的改进：SC-INR-exact

把全部非线性放到系数生成端，让输出对基线性：

- 编码器特征 → 每个位置的局部展开参数 {a_k, ω_k, φ_k}（可以由任意非线性网络生成）。
- 输出 = Σ_k a_k · W_k(c) · cos(πω_k·δ + φ_k) + 低频项，其中 W_k 是解析足迹响应，低频项用与足迹一致的面积积分上采样代替双线性。
- 性质：足迹积分精确；跨尺度一致性严格成立；非对称、s<1、s>4 自动正确；cell 从参数空间彻底消失。
- 代价：失去 LTE 那种"基之后再过 MLP"的表达力，对称倍率的 PSNR 可能下降。这是一个要用实验回答的取舍，不能预设。

这才是"方法"层面的命题：**把观测足迹解析地写进表示，使尺度条件在训练分布之外仍有定义，并以精确性换取可验证的一致性。**
