## 1. 命题 3 的两种口径

### 1.1 记号

逐频率标量信道：信号能量 P(ν)，有效噪声 N(ν)（传感器噪声折算 + 混叠/零空间），R(ν)=P/(P+N)。估计器使用的先验能量 Q(ν)，κ=Q/P。

多帧 ×s、T 帧、足迹 MTF 为 K(ν) 时，近似有
N(ν) ≈ N_alias(ν) + σ_n² / (ρ·|K(ν)|²)，ρ = T/s²（每个 HR 像素的观测数；E1 的 T=16、×4 时 ρ=1）。
盒足迹宽 w=s 个 HR 像素时 K(ν)=sinc(wν_x)·sinc(wν_y)，×4 时每轴在 ν=1/4、1/2 处为零，**零线穿过 b3、并贴着 b2 外沿**；随机位移造成的相位缺失使 N_alias 在某些频点也很大。

### 1.2 绝对口径（新写法，等价于命题 3）

P·Δ(R,κ) = **N²(Q−P)² / ((P+N)(Q+N)²)**（已数值核对，相对误差 <1e-9）。

四个区间（读这个式子就能看出谁付代价）：

| 条件 | 每频点超额误差 | 说明 |
|---|---|---|
| N ≪ P, Q | ≈ N²(Q−P)²/(P·Q²) | 二阶小，近乎免费 |
| P < N < Q（**高估窗**） | ≈ N | 与信号能量无关，可远大于 P |
| Q < N < P（低估窗） | ≈ P | 最多丢掉该频点信号 |
| N ≫ P, Q | ≈ (Q−P)²/N → 0 | 没信息，也就没代价 |

要点：**高估代价按 N 计、低估代价按 P 计。** 相对口径 Δ 把两者都除以 P，于是高估代价 (1−R)²/R 在 R→0 时发散；只要一个频点 R(ν)<1/2 且先验高估它，这个频点就按「噪声量」计价。

### 1.3 翻转推论（核对撰写线程 Cor. flip）

Δ(R,K) 与 Δ(R,1/K) 分子相同，分母分别为 (1−R+KR)² 与 (K(1−R)+R)²。两者之差的符号由
(1−R+KR) − (K−KR+R) = (K−1)(2R−1)
决定，故对任意 K>1：**Δ(R,K) > Δ(R,1/K) ⇔ R < 1/2**。已在 K∈[1.01,50]、R∈(0,1) 网格上数值核对。

适用条件（正文须写明）：
- 逐频率、标量、平稳；失配是**对称的倍数**（K 对 1/K）。
- 按频带平均代入时不保证：带内 R 不均匀会使翻转点偏移。E2 的稀疏 10% b1（R=0.92，却是高估代价大：0.110 vs 0.072）就是反例，原因是随机采样的混叠跨频带扩散（见 `结果-E2-谱失配代价-20261003.md` §2）。
- 草稿中「(1−R)²/R > 1 ⇔ R < 0.38」也正确：R < (3−√5)/2 ≈ 0.382。

### 2.3 修正判据（措辞以此为准）

**判据 M。** 比较两个表示（等效先验 Q₁、Q₂）时，计算
C(Q) = Σ_b E_b · Δ(R_b, κ_b(Q))，
其中 E_b 是频带能量，R_b 是匹配先验下的频带可恢复度，κ_b(Q) 是该表示在频带 b 的能量与 E_b 之比。C 小者预测为优。
- **适用**：对多个表示**排序**（D11-b ρ=0.856，E2 ρ=0.90）。
- **不适用**：从差距很小的候选中**挑出最优**（D11-c 1/3）；也不适用于非线性迭代拟合的表示（mrgrid、TV、ff 未测）。
- **事前版**：R_b 用通用 1/f² 先验和已知算子计算（d8），E_b、κ_b 用通用谱。事前版是否同样能排序，D11 没有测，**尚未检验**。
- **精确版**：对线性臂，用迹公式 E‖x−x̂‖² = tr((I−H_QA)C_P(I−H_QA)ᵀ) + σ²‖H_Q‖_F² 直接计算，没有近似误差。
- **不要写**：「三区标签本身决定赢家」或「A 区宁宽」的无条件版本。处方必须带上 κ_b 和所有频带的能量加权。

逐频率绝对口径 e(ν) = N²(Q−P)²/((P+N)(Q+N)²)（§1.2）在代数上正确，可用来**说明**为什么高估代价按 N 计；但在多帧、稀疏这类算子不对角的任务上，它的逐频率**预测**不准（本线程小模型、E2 稀疏任务），**不能作为证据引用**。

## 3. 两层框架的形式化

### 3.1 定义

- **事前层（线性层）**：R_b^lin(A, σ, P) = 1 − E‖Π_b(x − x̂_LMMSE(P))‖² / E‖Π_b x‖²。只依赖算子、噪声、先验谱；取 P 为通用 1/f² 时不需要任何数据。
- **网络层**：对训练好的网络 f，R_b^net = 1 − E‖Π_b(x − f(y))‖² / E‖Π_b x‖²，需要真值，是事后量。
- 关系：对线性平稳估计器（以及惰性训练近似下的傅里叶特征 MLP，命题 1 / NTK），R_b ≤ R_b^lin（命题 2）。非线性训练先验可以利用跨频带依赖，R_b^net 可超过 R_b^lin（M2、E3：C 区 12/12 格网络 > oracle）。

### 3.2 命题 3 在网络层能说什么、不能说什么

**能说（作为边界陈述，标为「刻画」而非定理）：**
- 若某频带 R_b^net ≈ 1，网络在该频带的输出几乎不依赖先验细节，部件消融的损失应趋于 0。F1 的 A 区 b1 损失 ≈ 0（LTE 0.0000）与此一致。
- 若某频带 R_b^net ≈ 0，网络在该频带没有恢复内容，也就没有可损失的东西。
- 损失只可能出现在 R_b^net 处于中段的频带。

**不能说：**
- 不能给定量排序。命题 3 推导要求「估计器 = 某个先验谱下的线性 Wiener」，网络不满足；把 R_b^net 代入 g(R)=R(1−R)² 的定量版已被 F1 的 H-F2 否定（0.49 / 0.55，阈值 0.5）。
- 不能给非对称方向。网络里没有定义良好的 κ，「高估/低估」在网络层无意义。
- 不能事前预测：R_b^net 需要真值；F1 的 H-F1（事前 R_lin）不成立（0.41 / 0.46）。

因此论文里：事前层的命题 3 是定理加预注册验证；网络层只能写「损失只出现在 R_net 中段频带」这一刻画。

### 3.3 新推导：读出算子 = 观测增益失配（连 SC-INR）

SC-INR 的有效部件是读出算子（足迹/sinc 积分）；LTE 的 cell 输入起类似作用。去掉它，等于网络对输出像素的足迹建模出错，在频域上是**观测增益失配**：估计器假设增益 K̃ = K(1+ε)，而真实是 K。

逐频率标量模型、先验匹配时，超额误差（按 P 归一）在小 ε 下为
**Δ_op(R, ε) ≈ ε² · R(1−2R)²**
（已数值核对：R=0.2 时 0.0719 vs 0.072；R=0.8 时 0.2878 vs 0.288；有限 ε=0.2、R=0.8 的蒙特卡洛 0.0100 vs 闭式 0.0101）。

与谱失配 g(R)=R(1−R)² 相比，形状不同：
- R→1 时 Δ_op → ε²，**不为零**：无噪声时用错增益，就是直接放大或缩小错误；
- R=1/2 时为 0：此时 Wiener 增益对 K 取极值，一阶不敏感；
- R→0 时为 0。

**这改变了对 F1 的解释。** F1 中 b1 损失 ≈ 0，按此式不是因为「A 区无杠杆」，而是因为低频 ε≈0：点采样与盒足迹在低频几乎一样。用 1−sinc(ν) 估计每轴的相对增益偏差（输出像素宽 1 HR px，ν 以 cycles/HR px 计），在频带上沿 ε ≈ 0.026（b1，ν=1/8）、0.10（b2，ν=1/4）、0.36（b3，ν=1/2），ε² 之比约 1 : 14 : 190。所以损失集中在 b2/b3、b1 为零，本身就由足迹偏差决定。

**seed1 LTE 对的事后核对**（27 格，`/mnt/project-files/f1_lte_cells.json`；F1 的 0.411 / 0.490 复算一致）：

| 预测量 | Spearman(·, L) |
|---|---:|
| g(R_lin) | 0.411 |
| g(R_net) | 0.490 |
| **ε_b²（只看频带）** | **0.664** |
| ε_b²·h(R_net) | 0.598 |
| ε_b²·g(R_net) | 0.567 |

ε_b² 按 1/|ν|² 加权、max-norm 频带：b1 6e-05、b2 0.0055、b3 0.072。b2/b3 内 18 格：ε_b² 0.610，g(R_net) 0.257。
**事后读法**：读出损失主要由足迹增益偏差的频带位置解释；乘上 R 因子（任何形式）没有改善。这是事后结果，不作确认。

**确认性检验已预注册并冻结**：`paper/derivation/预注册-G1-读出损失与足迹增益偏差-20261005.md`（sha256 548b26fe…，2026-10-04 22:29 UTC，早于任何 seed2/3 评测）。主判据 Spearman(ε_b², L) ≥ 0.5（4 组中 ≥3 组），另有顺序判据与「R 因子无增益」判据。SC-INR 对只用复核后的正确配对。

- 局限：网络不是线性 Wiener；LTE 训练时混合了多个倍率，无 cell 时网络学到的是「平均足迹」，真实 ε_b 应为与该平均足迹的偏差，不是 1−sinc 本身。1−sinc 只给数量级和频带顺序。

### 3.4 与 L2「cell 平均」预测量的关系（2026-10-05 补，同日按 L2b 结果修正）

L2（`/mnt/project-files/结果-L1L2-尺度坍缩与读出算子-20261005.md`）用完整模型对 cell 取平均来预测消融损失，seed1 Spearman 0.82（两对），高于 G1 的 ε_b²（0.676；本线程只用 LTE 对算得 0.664）。

**原先的推导（已被否定，保留供追溯）。** 去掉 cell 后，网络只能输出跨倍率的平均增益 Ḡ，相当于估计器增益偏离 g = g*(1+δ_s)。对线性估计，超额误差 = (g−g*)²(K²P+σ²) = δ²·R·P。这一代数本身正确。由此我推出一个层级：L2 实测的就是 δ²·R；算子假设失配的因子是 R(1−2R)²；G1 的 ε_b² 是最粗的代用量。我据此提出两条可检验的推论。

**L2b 检验结果（预注册 `预注册-L2b-增益失配层级-20261005.md`，服务器 sha 730289d6，23:04:43Z 冻结）：两条都不成立。**
- H-L2b-1：δ²·R 的排序应不低于 L_pred。实测 LTE 0.618 < 0.822，SC 0.651 < 0.824。**不成立**。
- H-L2b-2：δ²·R(1−2R)² 应更差。实测反而略高：0.695 > 0.618，0.705 > 0.651。**不成立**。
- 描述性：只用 δ_b² 本身，ρ 为 0.651 / 0.681。

**修正后的结论。**
1. 「cell 缺失 = 输出增益失配、因子为 R」这一解释**被否定**。L2 的预测力来自直接测量 cell 平均，不能由线性化增益失配公式复现。线性化一做，排序能力就从 0.82 掉到 0.62–0.65。
2. 在已检验的所有闭式量中，乘上任何 R 因子都没有稳定的改善。δ_b²、ε_b² 本身约 0.65–0.68，乘 R 或 R(1−2R)² 后在 0.60–0.71 之间，方向不一致。这与 §3.3 的 seed1 事后结果一致：**R 因子对读出损失没有可靠的解释力。**
3. 线性化失败的位置与 L2 的 H2b、H2c 相同：δ² 随倍率单调增大，但 ×2/×3 的 b3 上实际损失已经很大。这说明小倍率时 cell 提供的不只是「尺度/增益」信息，非线性的部分不能用逐频率增益描述。
4. 论文可写：读出损失可以由「完整模型的 cell 平均」事后预测（0.82，相关证据）；闭式的增益失配模型只能给出频带顺序（约 0.65–0.68），不能给出 R 依赖。不写「cell = 增益失配」的机理论断。
5. G1 已冻结，不改。它检验的是最粗的版本（只看频带的 ε_b²），预测仍然有效；其中 H-G3（R 因子无增益）与本节结论方向一致。
