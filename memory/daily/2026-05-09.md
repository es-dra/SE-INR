### 判断摘要

- `SC-INR+PhiZ` 在 seed1 全 benchmark PSNR 上是当前表内 All/OOD 最强模型：相对 `LTE` 的 All `+0.081 dB`、OOD `+0.085 dB`，36/36 个 benchmark-scale 组合胜出。
- 相对 `SC-INR`，`SC-INR+PhiZ` 的 All `+0.042 dB`、OOD `+0.030 dB`，33/36 个组合胜出；说明 feature-conditioned phase 是有希望的增量。
- 与强 baseline `LIIF-EQ` 相比，`SC-INR+PhiZ` 的 All 只高 `+0.019 dB`，OOD 高 `+0.030 dB`，ID 基本持平且略低；如果论文定位成“明显 SOTA PSNR”，证据偏弱。
- 当前最稳的论文主张仍是：decoder-side sampling consistency 改善 OOD scale robustness。`SC-INR+PhiZ` 可以作为增强版候选，但必须补 consistency/texture/continuous-scale 和多 seed。

### 对 PSNR 和尺度外推的解释边界

- PSNR 是 fidelity 指标，能说明在当前退化和评测协议下 MSE 更低，但不能单独证明感知质量、纹理真实性或采样一致性。
- 当前 OOD scale 评估的依据不是严格 scale equivariance，而是：训练中 decoder 学到连续局部内容表示，测试时改变 output cell/coordinate；SC-INR 类方法把 cell 约束到解析 sinc observation response 中，从而减少 learned cell-conditioned extrapolation 的自由度。
- `SC-INR+PhiZ` 的 feature-conditioned phase 在理论上比 LTE 的 cell-conditioned phase 更安全，因为 phase 不直接依赖 scale/cell；但这需要通过跨尺度一致性和 phase/omega 诊断验证。

### 下一步 gate

- Gate 1：补 `SC-INR+PhiZ` 的辅助指标，要求 OOD PSNR 不退化且 consistency 相对 `LTE` 仍显著改善，不能只看 benchmark PSNR。
- Gate 2：补 `SC-INR+PhiZ` 至少 3 seed 或关键 seed 复现，确认 `+0.03~0.08 dB` 不是 seed 偶然。
- Gate 3：做 `SC-INR+PhiZ w/o sinc` 或等价 sinc 消融，证明收益不是单纯来自额外 phase 参数。
- Gate 4：重做 qualitative crops、error maps 和 continuous-scale curve，用于解释 PSNR 小幅提升是否对应可见结构/纹理改善。

### 专家评审

- 可靠结论：`SC-INR+PhiZ` 是当前 seed1 PSNR 最优候选，值得进入下一轮验证；核心 `SC-INR` 的 3 seed OOD 优势已经比单 seed 更可靠。
- 证据不足：目前不能说 `SC-INR+PhiZ` 已经论文级显著优于所有现有模型；尤其相对 `LIIF-EQ` 的 All PSNR 差距很小，且缺少多 seed 和机制指标。
- 下一步是否合理：优先做 `SC-INR+PhiZ` 的辅助指标和消融，比立刻写“最终主模型”更稳；若 consistency 被破坏，需要考虑 phase 正则、残差幅度限制或退回无 phase 主线。
- 需要防止过度宣称：PSNR 小幅提升不能等价于视觉质量明显更好；OOD scale robustness 不能写成严格尺度等变；尺度外推的解释必须绑定解析 observation response 和当前 downsampling protocol。

### 理论深化判断

- 当前 SC-INR 理论如果只停留在“一维 Fourier box average 得到 sinc”确实偏浅；更强的写法应把它提升为“latent continuous content function + pixel observation operator”的框架。
- 最可辩护的理论主线：
  - 定义局部连续内容函数 $f_z(\delta)$；
  - 输出像素不是点采样，而是 observation footprint 上的线性观测 $O_c[f_z]$；
  - 对 Fourier basis，box observation 在频域对应解析 sinc response；
  - same-LR cross-scale consistency 可以解释为不同 observation operators 对同一 $f_z$ 的近似可交换性；
  - LTE 的 learned `phase(cell)` 则把同一内容变成 $f_{z,c}$，削弱这个可交换结构。
- 可形成 2-3 个轻量命题，而不是强行宣称严格 scale equivariance：
  - Fourier box observation 命题：单个 Fourier 分量的矩形 footprint 平均等价于 sinc 衰减；
  - observation consistency 命题：若 coarse pixel 是 fine pixel footprint 的面积平均，则同一 latent function 的观测在理想 box 情形下可交换；
  - bounded response 命题：signed bounded omega 使 cell response 在有限尺度范围内是有界、平滑、可诊断的，而 learned `phase(cell)` 没有采样物理约束。

### 未解决风险与下一步

- 理论写作必须明确是 decoder-side sampling consistency，不是 whole-network scale equivariance。
- 如果要把理论说得更有说服力，应补 synthetic Fourier/property test：对已知 Fourier 图像验证 SC-INR observation formula 与数值积分一致，并用 NoSinc/LTE 展示 violation。
- NoSinc 消融完成后，应把理论命题与 empirical gate 绑定：如果 NoSinc 不掉 consistency，则 sinc 因果 claim 必须降级。
