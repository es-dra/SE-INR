节点问题：

- 直接回答 `LTE -> SC-INR` 主脉络是否只有 PSNR 对比。
- 在同一 LR/crop/query/cell 协议下，同时检查 LTE 的 learned `h_p(c)`、SC-INR 的
  analytic `W(omega,c)`、MLP 前 effective amplitude proxy、输出 cell sensitivity 和
  footprint oracle tracking。

协议：

- seed1 checkpoints。
- models: `LTE`, `LTE-NoCellPhase`, `LTE-PhaseZ`, `SC-INR-NoPhi`, `SC-INR`,
  `SC-INR-NoSinc`。
- datasets: BSD100 / Urban100 sorted 前 5 张。
- base scale: x4。
- center crop: 64 HR pixels。
- query: 每图最多 256 个有效 query。
- cell multiplier: `1,2,4`。
- oracle: HR piecewise-constant box-average proxy。

subagent 使用：

- `Schrodinger` 审查机制指标有效性。
- 采纳意见：
  - LTE 只单独隔离 `h_p(c)=phase(rel_cell)`，不把完整 Fourier basis 误称为 cell phase。
  - SC-INR 的 effective amplitude 只定义为 MLP 前 Fourier input proxy。
  - 同时报告 `W` / `|W|` / active response / energy ratio，避免只用均值掩盖符号和幅度 caveat。
  - 负控保留 `LTE-NoCellPhase`、`LTE-PhaseZ`、`SC-INR-NoSinc`。

  - `SC-INR` active response delta RMS `0.30812`。
  - `SC-INR-NoSinc` active response delta RMS `0`。

证据支持的结论：

- 这次不再只是 `LTE vs SC-INR` 的 PSNR 对比；已经有同协议机制 gate。
- LTE 确实有随 cell 改变的 learned `h_p(c)` 信号。
- SC-INR 确实有随 cell 改变的 analytic active response 和 MLP 前 effective amplitude proxy。
- 在这个 crop-based HR box proxy 上，SC-INR 比 LTE 和 NoSinc 略好地跟随 footprint target。

未解决风险：

- 该诊断是 seed1、crop-based、小样本机制 gate，不是全图、多 seed 或主 benchmark。
- phase delta 和 response delta 不是同一物理量，不能用大小直接推导 PSNR。
- effective amplitude 仍然只是 MLP 前 proxy，不是最终 RGB 频谱振幅。
- 不能写 sinc 唯一因果、真实连续图像 exact box integral 或 strict scale equivariance。

下一步：

- 若论文正文需要直接回应 `LTE phase(cell) -> SC-INR W(omega,c)`，可以使用该表，但必须标成 diagnostic。
- 若要升级为更强证据，需要扩大 crop/image 覆盖或补多 seed；当前不建议自动扩大，因为计算代价较高且主 benchmark 已有。

专家评审：

证据不足：它不能证明 sinc 是唯一因果，也不能证明最终 RGB 是 exact box observation。
