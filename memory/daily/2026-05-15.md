证据支持的结论：

- footprint oracle gate 支持：final `SC-INR` 比 `SC-INR-NoSinc` 这类 cell-insensitive 负控更跟随
  HR box-average proxy；这解决了 same-LR consistency 会被 NoSinc 刷高的主要反例。
- `LTE-NoCellPhase` 和 `SC-INR-NoSinc` 对 cell multiplier 不响应，符合负控预期。
- 该诊断支持 analytic footprint response 作为机制解释，但不是最终 RGB exact box integral 证明。

未解决风险：

- oracle 是 HR piecewise-constant box proxy，不是真实连续图像积分。
- 结果是 seed1 小样本 diagnostic，不是 multi-seed 主证据。
- `SC-INR-NoPhi` 在 footprint oracle 上略强于 final `SC-INR`；不能写 final variant 在所有辅助指标上最强。
- 不能把该结果写成 sinc 唯一因果；NoSinc 的 benchmark 下降和 footprint oracle 负控只能共同支持机制合理性。

下一步：

- 如果需要正文强证据，可扩大 footprint oracle 覆盖或补更多 seeds；否则保持 appendix diagnostic。
- 论文主线应继续以 3-seed PSNR 为主证据，以 footprint oracle、response/omega 和 effective amplitude 作为机制补强。
