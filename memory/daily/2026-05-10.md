### 模型差异记录

- 完整 `SC-INR` 使用 registry name `sc_inr_signed_phiz`，结构为 signed bounded $\omega(z)$ + feature-conditioned $\phi(z)$ + analytic sinc response。
- `SC-INR-NoSinc` 使用 registry name `sc_inr_nosinc`，继承 `SCINRSignedPhiZ`，因此保留 signed bounded $\omega(z)$ 和 feature-conditioned $\phi(z)$。
- 唯一机制调整是 `use_sinc_response=False`：代码中将 Fourier response 权重从
  $W=\operatorname{sinc}(\omega_h c_h/2)\operatorname{sinc}(\omega_w c_w/2)$
  替换为 $W=1$。
- local ensemble、coordinate/cell 单位、encoder、coef、omega、phase、MLP 和 residual upinput 路径保持不变。

### 证据支持的结论

- seed1 benchmark 显示：移除 sinc 后，最终候选相对完整 `SC-INR` 明显变弱，尤其 ID 和 All 平均下降更明显。
- NoSinc 的 OOD 平均仍略高于 `LTE`，说明 signed $\omega(z)$ + $\phi(z)$ 本身也有贡献，不能把全部收益归因到 sinc。
- 当前更稳妥的论文表述是：NoSinc 消融提示 analytic observation response 对最终候选有贡献；但需要 auxiliary consistency 和多 seed 才能形成更强机制证据。

### 未解决风险与下一步

- `SC-INR-NoSinc` 还缺 same-LR consistency、PSNR-Y/SSIM-Y、texture/highpass RMSE；这些指标比 PSNR 更直接检验 sampling-consistency 机制。
- `SC-INR` final candidate 仍缺 seed2/seed3，不能把 seed1 NoSinc 差异写成最终统计结论。
- 后续建议优先运行 `SC-INR-NoSinc` auxiliary metrics，直接和 `LTE`、`SC-INR-NoPhi`、`SC-INR-NoPhi-Signed`、`SC-INR` 比较；若 NoSinc consistency 显著退化，机制证据会更完整。

### 专家评审

- 可靠结论：NoSinc 训练完成、完整 benchmark 已补齐且 36 项无缺失；实现差异确认为只关闭 analytic sinc response，未改 signed $\omega(z)$ 和 $\phi(z)$。
- 证据不足：当前只有 seed1 PSNR benchmark，不能证明 sinc 是唯一原因，也不能证明 multi-seed 统计稳定。
- 下一步是否合理：补 NoSinc auxiliary consistency 是最直接的机制验证；final `SC-INR` seed2/seed3 仍应作为后续统计闭环。
- 需要防止过度宣称：不要写 strict scale equivariance；不要把 NoSinc 单 seed 下滑写成严格因果证明；不要把 OOD 小幅差异脱离 variance 和 protocol 解释。

  consistency 指标会奖励这种自一致性，但没有验证 footprint observation 是否正确。

- 因此 claim ledger 已调整为：sinc 支持主要来自 full benchmark/fidelity 证据；
  current same-LR self-consistency 不能作为 sinc 改善 consistency 的证据。

### 专家评审

  `SC-INR`。
- 证据不足：该结果不能证明 NoSinc 的 observation model 更正确，也不能推翻 sinc
  在 full benchmark 上对 PSNR 的贡献；它主要说明现有 consistency 指标有偏好
  cell-independent decoder 的风险。
- 下一步是否合理：优先补 response/omega diagnostics 和 final `SC-INR` 多 seed；
  在论文中把 NoSinc aux 写成机制诊断 caveat，而不是正向主证据。
- 需要防止过度宣称：不要说 NoSinc 破坏 sampling consistency；不要说高
  same-LR consistency 等价于更好的 scale sampling consistency；不要说 sinc

### 证据支持的结论

- `SC-INR-NoSinc` 的高 same-LR self-consistency 可由 zero active cell response
  解释：它实际使用 `W=1`，所以同一坐标下改变 cell 不改变输出。
- 完整 `SC-INR` 不是 cell-independent；它保留非零 analytic attenuation 和非零
  cell-only output sensitivity。
- `SC-INR` 的 cell-only sensitivity 明显低于 LTE，符合“移除 learned
  cell-conditioned phase，改为解析 response”的机制预期。
- 该诊断加强了 claim ledger 中的 caveat：same-LR consistency 不是 standalone
  proof，必须结合 fidelity、response/omega 和 full benchmark。

### 未解决风险与下一步

- 当前 response/omega 诊断是小样本机制诊断，只覆盖两数据集前 5 张和最多 4096
  query points，不能替代 benchmark。
- active attenuation 在高倍率 x16/x30 数值很小，说明 sinc response 对 OOD 高倍
  的直接幅度影响可能弱；其 PSNR 贡献可能通过训练动态、x4/ID regularization、
  或与 phase/omega 的交互体现，需要更谨慎解释。
- `SC-INR-NoSinc` near-bound fraction 较高，后续可检查 omega 分布图或训练日志，
  但不能把它直接写成失败原因。
- 下一步若继续机制闭环，应优先设计 footprint correctness 指标，而不是继续堆叠
  same-LR self-consistency。

### 专家评审

- 可靠结论：NoSinc 的 zero active response 和 zero cell-only RMSE 是实现机制的
  直接结果；它解释了 NoSinc self-consistency 虚高。
- 证据不足：该诊断不能证明 sinc 是唯一因果，也不能单独解释 full benchmark 的
  PSNR 差异；尤其高倍率 active attenuation 很小，需要避免过度机制化叙事。
- 下一步是否合理：继续补 final `SC-INR` 多 seed 和更直接的 footprint correctness
  指标是合理的；不建议把 same-LR consistency 继续作为 sinc 消融的主要正证据。
- 需要防止过度宣称：不要把 cell-only sensitivity 小写成严格 scale equivariance；
  不要把 NoSinc zero sensitivity 写成更好；不要把小样本 omega near-bound 差异写成
  已证实失败机制。
