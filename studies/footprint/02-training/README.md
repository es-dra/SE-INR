# Footprint stage 02: matched 200-epoch arms

Arms, recipe and frozen predictions T1–T5: [`protocol.json`](protocol.json). Configs are generated by `make_configs.py` into `configs/train-div2k/footprint/`.

## Run (server)

```bash
cd /workspace/SE-INR/SE-INR-current && git pull
nohup python3 studies/footprint/02-training/orchestrate.py \
    --run-root /workspace/SE-INR/runs/claude-20261102-footprint-train-v1 --gpus 1,2 > /workspace/SE-INR/runs/footprint-train.log 2>&1 &
```

The orchestrator copies the repository into `code/`, trains each arm and seed on a free GPU (two at a time for `--gpus 1,2`), benchmarks the epoch-200 checkpoint on Set5/Set14/BSD100/Urban100/DIV2K at ×2/3/4/6/8/12 and marks `DONE_<arm>-s<seed>`. It is resumable: rerun the same command after an interruption. Priority order when GPUs are scarce: `--arms liif-asym-200ep,sc-inr-exact-200ep,lte-200ep,sc-inr-200ep,sc-inr-nosinc-200ep,lte-asym-200ep,lte-linear-200ep`.

## Baseline table for the 1000-epoch checkpoints (inference only)

```bash
cd /workspace/SE-INR/SE-INR-current
for m in liif lte sc-inr; do for s in 1 2 3; do
  CK=/workspace/SE-INR/SC-ASISR/artifacts/checkpoints/seed$s/$m/epoch-last.pth
  [ -f $CK ] && CUDA_VISIBLE_DEVICES=1 python3 tools/benchmark.py --ckpt $CK --name $m-1000ep-s$s \
      --data-root /workspace/SE-INR/Data --datasets set5 set14 bsd100 urban100 div2k --scales 2 3 4 6 8 12 \
      --out /workspace/SE-INR/runs/bench-1000ep.jsonl
done; done
```

## Footprint evaluation of the new arms

After the arms finish, write `ckpts.json` mapping `"<arm>:seed<N>"` to `save/<arm>-s<N>/epoch-last.pth` (include `liif-200ep` from the stage-05/08 runs) and reuse stage 01:

```bash
python3 studies/footprint/01-inference/freeze.py --run-root /workspace/SE-INR/runs/claude-20261102-footprint-eval-v1 \
    --checkpoints ckpts.json --epoch 200 --tag stage02-200ep
cd /workspace/SE-INR/runs/claude-20261102-footprint-eval-v1 && bash launch.sh 1,2
python3 score.py --run-root . --primary sc-inr-exact && cp score/summary.json score/summary-exact.json
```

Copy back `bench.jsonl`, `FREEZE.json`, `logs/*.log` tails, and the eval run's `score/`, `FROZEN.sha256`, `input_manifest.json`.
